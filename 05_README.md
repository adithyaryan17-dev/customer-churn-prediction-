# Customer Churn Prediction

## Overview

Machine learning project to predict customer churn in retail banking.

## Features

-   Data preprocessing
-   Exploratory Data Analysis
-   Feature engineering
-   Classification models
-   Explainability
-   Streamlit dashboard

## Project Structure

-   Notebook
-   Streamlit app
-   Research paper
-   Executive summary

## Tech Stack

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, XGBoost, SHAP,
Streamlit

## How to Run

1.  Open the notebook in Google Colab.
2.  Upload the churn dataset.
3.  Run all cells.
4.  Train models.
5.  Launch Streamlit dashboard.
